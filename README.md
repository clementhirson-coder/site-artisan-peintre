# Site vitrine — [NOM DE L'ENTREPRISE À FOURNIR]

Tout le site tient dans un fichier : `index.html`. Les photos sont dans `assets/`.

- **Modifier un texte** — ouvrir `index.html` avec un éditeur de texte (Bloc-notes, TextEdit), chercher la phrase, la remplacer, enregistrer.
- **Remplacer une photo** — déposer la nouvelle image dans `assets/chantiers/` en gardant exactement le même nom de fichier que l'ancienne.
- **Ajouter un chantier** — copier un bloc `<figure>…</figure>` dans `index.html`, le coller juste en dessous, changer la photo et la légende.
- **Republier** — sur dash.cloudflare.com, ouvrir le projet, « Créer un déploiement », glisser le dossier complet dans la zone prévue. En ligne en une minute.
- **En cas d'erreur** — ne rien supprimer : revenir à la version précédente depuis l'onglet « Déploiements » de Cloudflare.

Les passages surlignés en jaune à l'écran sont les informations restant à fournir. Ils disparaissent une fois remplacés.
